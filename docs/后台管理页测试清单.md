# 后台管理页测试清单（B1–B5、B7）

入口：浏览器打开 `http://<服务器>:8088/console/admin`，或在 `/console` 页头点「管理页」。两个页面共用一次登录。
准备：一个在线账号（下面叫 A），最好再有一个离线账号（B）。改玩家数据的操作都会在 `backups/admin-*`（服务端目录的上一级，和任务调整同一个目录）生成整档备份。

## 公共层（B1）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 登录 | 直接打开 `/console/admin` | 没登录时出现密码框；在 `/console` 登录过就直接进 |
| 导航 | 依次点顶部各页 | 每页能打开；「卡池排期」是占位说明；「控制台 / 任务调整」回到旧页 |
| 玩家下拉 | 任意页点「刷新玩家」 | 在线的排前面并显示 AR，离线的显示「离线」 |
| 登录过期 | 重启服务端后在管理页随便点一个按钮 | 回到密码框，提示「登录已过期」 |

## 全服公告（B2）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 顶部立即发 | 形式选「顶部公告」，时间留空，写一句话，发送 | A 屏幕上方出现这句话；列表里状态「已发完」，进度 1/1，显示在线人数 |
| 弹窗立即发 | 形式选「弹窗」再发 | A 弹出要点「确定」的消息框 |
| 定时发 | 发送时间选 2 分钟后 | 列表里「待发送」；到点（误差 5 秒内）A 收到；状态变「已发完」 |
| 重复发 | 共 3 次、间隔 1 分钟 | 每分钟收到一次，进度 1/3→3/3 |
| 取消 | 定时公告到点前点「取消」 | 状态「已取消」，到点不再发 |
| 重启保留 | 排一条 10 分钟后的，重启服务端 | 列表里还在，到点照常发 |
| 已知限制 | — | 只发给发送时在线的人，不补发；顶部公告用的是协议里三个文字字段都填的老办法，如果某种界面不显示，回报一下 |

## 发邮件（B3）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 单人、在线 | 收件人选 A，标题、正文填中文，挑 2 个附件（如原石、大英雄的经验），发送 | A 立刻有新邮件红点；标题、正文、发件人「派蒙」正确；附件能领取，领取后背包和原石数正确 |
| 单人、离线 | 收件人选 B 再发 | 提示发送成功；B 上线后邮箱里有这封 |
| 全服 | 收件人选「全服」 | 先弹确认框；在线、离线账号各收到一封（每人一封，互不影响） |
| 拆封 | 附件挑 12 种 | 收到两封，标题带「（1/2）」「（2/2）」 |
| 星标、有效期 | 勾星标，有效期 1 天 | 邮件带星标，显示剩余 1 天左右 |
| 校验 | 不填标题直接发 | 红色提示「请填写标题」，不发送 |
| 发送记录 | 页面底部「最近发送」 | 新发的排在最上面 |

## 发物品（B5）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 分类 | 左边点「天赋」「周本」「特产」「经验书」「食物」「任务道具」「货币」等 | 右边只显示该类；有小类的大类下面能再细分（如圣遗物按部位） |
| 搜索 | 搜「风车菊」、搜一个 ID | 能找到 |
| 进背包 | 选 A，方式「自动」，篮子里放原石×1600、某个天赋书×10、一把武器×2，发放 | A 弹「获得物品」；背包里数量正确，武器是 2 把 1 级的；结果里有备份 ID |
| 离线自动转邮件 | 选 B，方式「自动」 | 结果显示「邮件 N 种」；B 上线后从邮件领取 |
| 只发邮件 | 选 A，方式「只发邮件」 | A 收到「物品发放」邮件，背包不直接变 |
| 只进背包、离线 | 选 B，方式「只进背包」 | 红色提示玩家不在线 |
| 常用按钮 | 点「原石×1600」两次 | 篮子里原石数量变 3200 |

## 账户编辑（B4，只能改在线玩家）

改完都应当**不掉线、当场看到**；每次保存右上角显示新的备份 ID。

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 读取 | 选 A，点「读取」 | 显示等级、货币、角色、武器、圣遗物、材料；离线账号在下拉里是灰的 |
| 冒险等级 / 世界等级 | 改冒险等级 +1、世界等级 -1，保存 | 游戏里派蒙菜单立刻显示新等级；世界等级在单人世界里生效 |
| 货币 | 原石改成 12345，保存 | 游戏里原石立刻变 12345 |
| 角色等级 | 某角色改 80 级、突破留空不动 | 角色面板 80 级，突破阶段自动对上 |
| 天赋 | 三个天赋改成 9/9/9 | 天赋界面立刻显示 9 |
| 命座往上 | 0 命改 2 命 | 命座界面点亮 2 个 |
| 命座往下 | 2 命改回 0 命 | 画面闪一下（重载场景），命座界面恢复 0 |
| 好感 | 改 10 | 角色好感 10 级 |
| 加角色 | 「加入角色」选一个未拥有的 | 游戏里提示获得角色，带初始武器；不会自动进队 |
| 武器 | 一把武器改 90 级、精炼 5，保存 | 背包里立刻更新；装备着的角色攻击力跟着变 |
| 圣遗物升级 | +0 改 +20 | 主词条升到满；副词条按游戏规则多 5 次（加满 4 条后再强化） |
| 圣遗物降级 | 把 +20 改小 | 红色提示只能往上升级 |
| 删除 | 删一件未装备、未上锁的武器 | 背包里消失；装备中或上锁的提示先卸下/解锁 |
| 材料 | 某材料改成 0 / 改成 999 | 背包里消失 / 数量变 999 |

## 活动排期（B7）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 列表 | 打开页面 | 默认只显示已配置或改过的活动（目前 9 个），标出「运行中」、有无专用处理器；切「全部活动」约 400 个 |
| 关闭 | 把 5344「无忧无虑大雪仗」取消「开启」，保存，**重启服务端**，A 重新登录 | 活动页里没有这个活动；后台这一行显示「后台已改」「未运行」 |
| 改时间 | 某活动结束时间改成明天，保存，重启，重新登录 | 活动页显示的剩余时间对上 |
| 恢复默认 | 点「恢复默认」，重启 | 回到原来的开关和时间 |
| 新开 | 「全部活动」里找一个不在默认配置里、有处理器的（如 5050 镜花听世），勾开启、填起止时间，保存，重启 | 后台显示「运行中」；游戏里能否看到取决于客户端认不认推断的排期号（5050001），看不到就回报 |

## 出问题时

- 页面红字就是服务端返回的原因；500 的完整异常在 `/console` 的服务器日志里（搜 `Admin API`）。
- 改坏了玩家数据：备份目录 `backups/admin-<操作>-<UID>-<时间>-*`，里面是改之前该玩家所有集合的 JSON，可以按 `quest-adjust` 那套方式人工恢复（本期没做一键回滚）。
