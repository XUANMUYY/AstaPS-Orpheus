# 后台管理页测试清单

入口：浏览器打开 `http://<服务器>:8088/console/admin`；旧地址 `/console` 会自动跳过来。整个后台只有这一个站点、一处登录。
布局照「原神后台管理页模板」：左侧深色导航按「给玩家东西 / 改玩家数据 / 通知和排期 / 看服务器」分组，默认进首页。字体 Noto Sans SC 从 Google Fonts 加载，连不上时用系统字体，不影响功能。
准备：一个在线账号（下面叫 A），最好再有一个离线账号（B）。改玩家数据的操作都会在 `backups/admin-*`（服务端目录的上一级，和任务调整同一个目录）生成整档备份。

## 公共层（B1）

| 测什么 | 怎么测 | 预期 |

| 首页 | 登录后看首页 | 按分组列出能做的事（每张卡片一句说明），右边是服务器状态、在线账号（带「改数据」「发东西」）和「第一次用？」说明 |

| 快速搜索 | 任意页按 Ctrl+K，或点导航顶上「我想……」 | 弹出搜索框；↑↓ 选、回车打开、Esc 关；切页面后自动关 |
| 导航 | 依次点左侧各项 | 每页能打开，当前页高亮，浏览器标签标题跟着变；「卡池排期」是占位说明 |
| 手机宽度 | 浏览器窗口拉窄到手机宽度（或用手机打开） | 导航收成顶栏，点 ☰ 展开，点了某页后自动收起；页面不横向滚动 |

| 登录过期 | 重启服务端后在管理页随便点一个按钮 | 回到密码框，提示「登录已过期」 |

## 账户编辑（B4，只能改在线玩家）

改动先进右侧「待保存的改动」（显示 原值 → 新值，可单项 × 撤销或「全部撤销」），点「保存 N 项」一次写入：只备份一次，改完**不掉线、当场看到**，下方显示「已生效 N/N 项，备份 …」。
同步方式（2026-10-25 用户确认）：只能改在线玩家，每项改动用游戏自己的接口执行并发对应的同步包，实时生效、不踢下线。例外：命座往下调时会重载一次场景（画面闪一下）；昵称和签名游戏不推送，玩家重新登录后才显示。

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 读取 | 右上角选 A | 出现概要卡和 6 个标签页；离线账号在下拉里是灰的 |
| 冒险等级 / 世界等级 | 「基本信息」改冒险等级 +1、世界等级 -1，保存 | 游戏里派蒙菜单立刻显示新等级；世界等级在单人世界里生效 |
| 昵称 / 签名 | 改昵称、签名，保存，A 重新登录 | 重登后显示新昵称和签名 |
| 货币 | 「货币」页原石改成 12345、纠缠之缘改成 20，保存 | 游戏里立刻变 |
| 一次多项 | 同时改两个角色的等级和一个材料数量，保存 | 待保存列表 3 项，一次保存全部生效，只生成一份备份 |
| 角色等级 | 某角色改 80 级、突破留空不动 | 角色面板 80 级，突破阶段自动对上 |
| 天赋 | 三个天赋改成 9/9/9 | 天赋界面立刻显示 9 |
| 命座往上 | 0 命改 2 命 | 命座界面点亮 2 个 |
| 命座往下 | 2 命改回 0 命 | 画面闪一下（重载场景），命座界面恢复 0 |
| 好感 | 改 10 | 角色好感 10 级 |
| 加角色 | 「角色」页下拉选一个未拥有的，点「加入」，保存 | 游戏里提示获得角色，带初始武器；不会自动进队 |
| 武器 | 一把武器改 90 级、精炼 5，保存 | 背包里立刻更新；装备着的角色攻击力跟着变 |
| 圣遗物升级 | +0 改 +20 | 主词条升到满；副词条按游戏规则多 5 次（加满 4 条后再强化） |
| 圣遗物降级 | 把 +20 改小 | 红色提示只能往上升级 |
| 删除 | 删一件未装备、未上锁的武器，保存 | 背包里消失；装备中或上锁的「删除」按钮是灰的 |
| 材料 | 某材料改成 0 / 改成 999 | 背包里消失 / 数量变 999 |

## 任务进度（推进或回退剧情）

主流程三步：选要跳过的剧情（常用主线 / 按地区 / 逐章挑选）→ 右侧「范围预览」核对 → 生成计划并执行。按地区 × 类别组合、停止点、目标 JSON 收在「高级筛选」里；撤销与备份收在右侧折叠块里。

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 选账号 | 点「刷新在线账号」 | 下拉显示在线账号，标「在大世界，可以执行」或「场景 N，要先回大世界」；选中后 UID 自动填上 |
| 从其他页跳来 | 在线玩家页点某行的「任务进度」 | 直接带上这个 UID |
| 任务目录 | 第一次打开页面 | 显示「正在加载任务目录…」，几秒后出现常用主线卡片；失败时有「重试」 |
| **跳过蒙德主线** | 点卡片「序章 · 蒙德」 | 卡片变蓝显示「已选」；右侧预览出现序章三幕，「38 个主任务，分布在 3 个章节」；再点一次取消 |
| 常用主线顺序 | 看卡片 | 序章、第一章、第二章……第七章按游戏顺序，「间章」在最后；每张卡写着几幕和各幕名称，地区明确的才标地区 |
| 按地区 | 点「蒙德全部主线（4 幕）」 | 选中序章三幕加「间章 第四幕 · 悖理」；鼠标悬停能看到包含哪几幕；预览里能看到多出来的悖理 |
| 逐章挑选 | 展开「逐章挑选」 | 按类别（魔神任务、传说任务、邀约任务……）折叠，里面按系列（序章、第一章……）分组，每行「序章 第一幕 · 捕风的异乡人」带地区和任务数；组标题的勾选框整组勾选，部分选中显示半勾 |
| 搜索 | 逐章挑选里搜「捕风」「温迪」「1101」 | 分别列出匹配的章节和单个主任务，可以直接勾 |
| 范围预览 | 每次改勾选 | 0.35 秒内自动刷新：主任务总数、按章节折叠的主任务名；每个主任务旁有「排除」 |
| 已选标签 | 看预览顶部 | 已选章节、单个主任务、被排除的主任务（红色「排除：…」）都列成标签，点 × 去掉 |
| 全部清空 | 点「全部清空」 | 勾选、排除、高级筛选、停止点都清掉，预览回到「还没选」 |
| 生成计划 | 选好后点「生成计划（只读，不改数据）」 | 显示步骤数、阻断数、补发邮件数、预计耗时；没有阻断时绿色「可以执行」，写明执行后会被强制下线、重新登录即可看到 |
| 阻断 | 选「蒙德全部主线」后生成计划（若悖理有阻断） | 红框写「有 N 处阻断，分布在 M 个主任务里」，下面每个主任务一张卡：主任务名、所属章节、中文原因；原始代码在「技术细节」里 |
| 一键排除 | 点「排除这 M 个主任务后重新生成」 | 这些主任务出现在已选标签里（红色），自动重新生成计划，阻断应减少或清零 |
| 排除也没用 | 设一个停止点导致阻断 | 对应原因旁标「排除也没用」，并提示去掉依赖它们的章节或停止点 |
| 高级筛选 | 展开后点地区「蒙德」+ 类别「魔神任务」 | 上方说明写清「同一行任一个、不同行同时满足」；预览给出对应范围 |
| 目标 JSON | 高级筛选里勾「直接用下面的目标 JSON」，或上传 .json | 预览和计划都按 JSON 走；已选标签显示「使用目标 JSON」；超过 1 MiB 的文件被拒 |
| 选择变了 | 生成计划后改一下勾选 | 「确认执行」变灰，要重新生成 |
| 执行 | 没有阻断时点「确认执行」 | 弹红色确认框写明步数、邮件数和会被强制下线；进度每 2 秒刷新；完成后提示「重新登录就能看到」，撤销框自动填上 |
| 备份与撤销 | 展开「撤销与备份」，点「查看备份」；账号离线后点「撤销这次调整」 | 列出备份，「填入」把备份号填进撤销框；撤销前弹确认框 |

## 出问题时

- 页面红字就是服务端返回的原因；500 的完整异常在「服务器日志」页（过滤 `Admin API`）。
- 改坏了玩家数据：备份目录 `backups/admin-<操作>-<UID>-<时间>-*`，里面是改之前该玩家所有集合的 JSON，可以按 `quest-adjust` 那套方式人工恢复（本期没做一键回滚）。
