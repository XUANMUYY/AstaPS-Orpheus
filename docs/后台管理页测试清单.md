# 后台管理页测试清单（B1–B5、B7）

入口：浏览器打开 `http://<服务器>:8088/console/admin`，或在 `/console` 页头点「管理页」。两个页面共用一次登录。
布局照「原神后台管理页模板」：左侧深色导航（公告与活动、发邮件、账户编辑、发物品；下面是任务进度、卡池排期占位、日志与命令）。字体 Noto Sans SC 从 Google Fonts 加载，连不上时用系统字体，不影响功能。
准备：一个在线账号（下面叫 A），最好再有一个离线账号（B）。改玩家数据的操作都会在 `backups/admin-*`（服务端目录的上一级，和任务调整同一个目录）生成整档备份。

## 公共层（B1）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 登录 | 直接打开 `/console/admin` | 没登录时出现密码框；在 `/console` 登录过就直接进 |
| 导航 | 依次点左侧各项 | 每页能打开，当前页高亮；「卡池排期」是占位说明；「任务进度」「日志与命令」回到 /console |
| 玩家 | 发物品、发邮件的 UID 框输入或从候选里选 | 旁边出现「昵称 · 在线 AR…」或「离线」；输错显示「没有这个 UID」 |
| 登录过期 | 重启服务端后在管理页随便点一个按钮 | 回到密码框，提示「登录已过期」 |

## 公告与活动页 · 全服公告（B2）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 顶部立即发 | 选「顶部滚动」「立即发布」，写一句话，点「发布公告」 | A 屏幕上方出现这句话；「最近发出」里有这条和在线人数 |
| 弹窗立即发 | 选「弹窗」再发 | A 弹出要点「确定」的消息框 |
| 定时发 | 选「定时发布」，时间选 2 分钟后 | 「排队中」出现这条；到点（误差 5 秒内）A 收到，移到「最近发出」 |
| 重复发 | 定时发布，共 3 次、间隔 1 分钟 | 每分钟收到一次，排队中显示 1/3→3/3 |
| 取消 | 排队中的公告点「取消」 | 到点不再发，最近发出里显示「已取消」 |
| 重启保留 | 排一条 10 分钟后的，重启服务端 | 列表里还在，到点照常发 |
| 已知限制 | — | 只发给发送时在线的人，不补发；顶部公告用的是协议里三个文字字段都填的老办法，如果某种界面不显示，回报一下 |

## 发邮件（B3）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 预览 | 填标题、正文、加附件 | 右侧深色「游戏内预览」同步显示标题、正文、发件人、有效期和附件格子 |
| 单人、在线 | 「单个玩家」填 A 的 UID，标题、正文填中文，点「从物品清单添加」挑 2 个附件（如原石、大英雄的经验），发送 | A 立刻有新邮件红点；标题、正文、发件人「派蒙」正确；附件能领取，领取后背包和原石数正确 |
| 单人、离线 | 收件人选 B 再发 | 提示发送成功；B 上线后邮箱里有这封 |
| 全服 | 点「全服（含离线）」 | 显示将发给几个账号；按钮变「发给全服」，先弹确认框；在线、离线账号各收到一封 |
| 定时发 | 发送时间选「定时发送」，2 分钟后 | 右侧「待发送」出现；到点（误差 15 秒内）A 收到；可以取消；重启服务端后仍会发 |
| 模板 | 填好后点「存为模板」，清空，再从「载入模板…」选回来 | 标题、正文、附件都回来（模板只存在这个浏览器里） |
| 拆封 | 附件挑 12 种 | 收到两封，标题带「（1/2）」「（2/2）」 |
| 星标、有效期 | 勾星标，有效期选 7 天 | 邮件带星标，显示剩余 7 天左右；「永久」约 10 年 |
| 校验 | 不填标题直接发 | 红色提示「请填写标题」，不发送 |
| 发送记录 | 页面底部「最近发送」 | 新发的排在最上面 |

## 发物品（B5）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 分类 | 左边点「天赋」「周本」「特产」「经验书」「食物」「任务道具」「货币」等 | 中间卡片只显示该类，卡片按星级上色；有小类的大类上方出现小类按钮（如特产按地区、圣遗物按部位） |
| 搜索 | 搜「风车菊」、搜一个 ID | 能找到 |
| 进背包 | UID 填 A，方式「直接进背包」，篮子里放原石×1600、某个天赋书×10、一把武器×2，发放 | A 弹「获得物品」；背包里数量正确，武器是 2 把 1 级的；结果里有备份 ID |
| 走邮件 | UID 填 A 或 B，方式「走邮件」 | 收到「物品发放」邮件，背包不直接变；B 上线后能领 |
| 进背包、离线 | UID 填 B，方式「直接进背包」 | 红色提示玩家离线，请改用走邮件 |
| 发放篮 | 用 −/+ 或直接改数量，点 × 移除 | 数量和种数跟着变 |
| 常用按钮 | 点「原石×1600」两次 | 篮子里原石数量变 3200 |

## 账户编辑（B4，只能改在线玩家）

改动先进右侧「待保存的改动」（显示 原值 → 新值，可单项 × 撤销或「全部撤销」），点「保存 N 项」一次写入：只备份一次，改完**不掉线、当场看到**，下方显示「已生效 N/N 项，备份 …」。
注意：模板里写的是「在线则强制下线后写入」，这里实现成在线实时同步、不踢人（理由见汇报）；如果要改回强制下线，跟主会话说。

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 读取 | 右上角选 A | 出现概要卡和 6 个标签页；离线账号在下拉里是灰的 |
| 冒险等级 / 世界等级 | 「基本信息」改冒险等级 +1、世界等级 -1，保存 | 游戏里派蒙菜单立刻显示新等级；世界等级在单人世界里生效 |
| 昵称 / 签名 | 改昵称、签名，保存，A 重新登录 | 重登后显示新昵称和签名 |
| 货币 | 「货币」页原石改成 12345、纠缠之缘改成 20，保存 | 游戏里立刻变 |
| 一次多项 | 同时改两个角色的等级和一个材料数量，保存 | 待保存列表 3 项，一次保存全部生效，只生成一份备份 |
| 角色等级 | 某角色改 80 级、突破留空不动 | 角色面板 80 级，突破阶段自动对上 |
| 天赋 | 三个天赋改成 9/9/9 | 天赋界面立刻显示 9 |
| 命座往上 | 0 命改 2 命 | 命座界面点亮 2 个 |
| 命座往下 | 2 命改回 0 命 | 画面闪一下（重载场景），命座界面恢复 0 |
| 好感 | 改 10 | 角色好感 10 级 |
| 加角色 | 「角色」页下拉选一个未拥有的，点「加入」，保存 | 游戏里提示获得角色，带初始武器；不会自动进队 |
| 武器 | 一把武器改 90 级、精炼 5，保存 | 背包里立刻更新；装备着的角色攻击力跟着变 |
| 圣遗物升级 | +0 改 +20 | 主词条升到满；副词条按游戏规则多 5 次（加满 4 条后再强化） |
| 圣遗物降级 | 把 +20 改小 | 红色提示只能往上升级 |
| 删除 | 删一件未装备、未上锁的武器，保存 | 背包里消失；装备中或上锁的「删除」按钮是灰的 |
| 材料 | 某材料改成 0 / 改成 999 | 背包里消失 / 数量变 999 |

## 公告与活动页 · 活动排期（B7）

| 测什么 | 怎么测 | 预期 |
|---|---|---|
| 列表 | 打开页面 | 默认只显示已配置或改过的活动（目前 9 个），每行一个开关，标出「已实现 / 只有入口，玩法未实现」和「运行中」；切「资源里全部活动」约 400 个 |
| 关闭 | 把 5344「无忧无虑大雪仗」的开关关掉，点「保存排期」，**重启服务端**，A 重新登录 | 活动页里没有这个活动；后台这一行显示「后台已改」「未运行」 |
| 改时间 | 某活动结束时间改成明天，保存排期，重启，重新登录 | 活动页显示的剩余时间对上 |
| 未保存提示 | 改了开关不保存 | 底部显示「N 个活动有改动未保存」 |
| 恢复默认 | 点「恢复默认」，确认，重启 | 所有后台改过的活动回到原来的开关和时间 |
| 新开 | 「资源里全部活动」里找一个不在默认配置里、已实现的（如 5050 镜花听世），打开开关、填起止时间，保存排期，重启 | 后台显示「运行中」；游戏里能否看到取决于客户端认不认推断的排期号（5050001），看不到就回报 |

## 出问题时

- 页面红字就是服务端返回的原因；500 的完整异常在 `/console` 的服务器日志里（搜 `Admin API`）。
- 改坏了玩家数据：备份目录 `backups/admin-<操作>-<UID>-<时间>-*`，里面是改之前该玩家所有集合的 JSON，可以按 `quest-adjust` 那套方式人工恢复（本期没做一键回滚）。
