## 怎么运行

```bash
python tools/resource-export/export_gacha_prefabs.py --client "F:/Fork Reversed/Genshin Impact/ForkClient"
```

- 只读扫描 `<client>/YuanShen_Data/StreamingAssets/AssetBundles` 与 `Persistent/AssetBundles` 下全部 `.blk`（约 2200 个，8 进程约 3–4 分钟），不启动游戏。
- 结果写到 `data/admin-catalog/gacha_prefabs.json`（机器可读，含证据类型、来源 blk、同块图标、推断、建议），本文件文末的生成段落同时被重写。
- 脚本启动时读取上次的 `gacha_prefabs.json` 做对比，打印新增和消失的编号；`--no-doc` 只写 json，`--out`/`--doc` 可改输出位置。
- 脚本只给建议，不改服务端卡池配置：要采用时，手动把编号加进 `src/main/resources/defaults/data/GachaPrefabAvailable.json`，并在 `Banners.json` 写对应卡池。

## 怎么看结果

- 证据：P=`GachaShowPanel_A###`（界面 prefab），T=`UI_Tab_GachaShowPanel_A###`（页签图），U=`UI_Gacha_A###_*`（UP 素材）。blk 里只有头部是明文，**没有证据不等于不存在**（武器池界面尤其如此）。
- 推断的归属：A280 起按「角色池、角色池2、武器池」三个一组（A280–A303 在社区表里逐个核对过，之后是外推）；同一个 blk 里出现的角色/武器图标只是线索，一个 blk 往往装着几个卡池的资源。所有「推断」都需要实机确认。
