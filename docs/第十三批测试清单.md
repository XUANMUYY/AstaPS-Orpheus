# 第十三批测试清单（integrate-13）

2026-10-26 整理。这一批合入 6 个修复分支：`fix-quest-exec`、`fix-talk`、`fix-gadget`、`fix-world`、`fix-login`、`fix-economy`。条目编号对应三轮缺口盘点的 `items.json`。

**账号**
- **测试号 1**（UID 100000001）：主测账号，走正常路线。
- **测试号 2**（UID 100000002）：对照账号，用来测「条件不满足应被拒绝」。需要低等级、未解锁的状态时用它；等级不合适就先在后台调整。

**怎么判断出了问题**
- 宿主日志里出现 `[Talk] ... rejected`，说明对话被开始条件拦下了。如果拦的是正常对话，把这一行记下来。
- 看到 `handler_failed` 或异常堆栈，也记下来。
