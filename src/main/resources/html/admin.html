任务进度

把一个账号的剧情直接推进到指定位置（比如跳过蒙德主线），奖励照常补发。三步：选要跳过的剧情 → 看范围 → 生成计划并执行。

执行前必读账号要在线，站在自己的大世界（场景 3）里别动。执行完会被强制下线，重新登录就能看到结果；任务道具直接进背包，其余奖励走邮件。
